## Rule
WHEN a user with an active account submits the right email and password, THE SYSTEM SHALL return an access token valid for 8 hours.
IF the same email fails to sign in 5 times within 15 minutes, THEN THE SYSTEM SHALL lock sign-in for that email for 15 minutes.

## Acceptance criteria
- Right credentials → 200 with a token, and GET /auth/me with that token → 200
- Wrong password → 401, with the same message as an unknown email
- 5 failures within 15 minutes → the next attempt returns 423, even with the right password
- After the 15-minute lock, the right password → 200
- No token or an invalid token → 401

## Rule
WHEN an admin or a manager searches the directory, THE SYSTEM SHALL return the users whose name or email contains the search text, filtered by role and status, 20 per page by default.
IF the requested page size is above 100, THEN THE SYSTEM SHALL refuse the request with 422.

## Acceptance criteria
- Search "ali" → users whose name or email contains "ali", in any letter case
- Filter role=manager and status=active → only active managers
- No page size → 20 per page, with the total count
- Page size above 100 → 422
- Member → 403

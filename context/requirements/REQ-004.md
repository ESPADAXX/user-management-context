## Rule
WHEN an admin invites an email with a role, THE SYSTEM SHALL create a single-use invitation link valid for 72 hours.
WHEN an invitee accepts a valid invitation with a name and a password, THE SYSTEM SHALL create an active account with the invited role.
IF the invitation is expired or already used, THEN THE SYSTEM SHALL refuse it with 410.

## Acceptance criteria
- Admin invites an email → 201, expiring 72 hours later
- Invitee accepts → 201, account active with the invited role
- Accepting twice, or after 72 hours → 410
- Inviting an email that already has an account → 409
- Manager or member invites → 403

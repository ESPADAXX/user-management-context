## Rule
THE SYSTEM SHALL give each user exactly one role: admin, manager or member.
WHEN an admin changes a user's role, THE SYSTEM SHALL apply it from that user's next request.
IF a role change would leave no active admin, THEN THE SYSTEM SHALL refuse it with 409.

## Acceptance criteria
- Admin sets a role → 200, and the user's next request uses the new role
- Manager or member changes a role → 403
- Demoting the last active admin → 409
- Member reads another user's profile → 403, and reads their own → 200

## Rule
WHEN an admin submits a new user with a unique email, a name, a role and a password of at least 10 characters, THE SYSTEM SHALL create an active account and return it without the password.
IF the email is already used, THEN THE SYSTEM SHALL refuse the request with 409.

## Acceptance criteria
- Admin creates a valid user → 201, status active, no password in the response
- Email already used, in any letter case → 409
- Password shorter than 10 characters or invalid email → 422
- Manager or member → 403

## Rule
WHEN a user account is created, updated, re-roled, deactivated or reactivated, THE SYSTEM SHALL push the change to every connected admin and manager within 2 seconds.
IF a connection has no valid token, THEN THE SYSTEM SHALL refuse it.
WHILE a member is connected, THE SYSTEM SHALL not send them directory events.

## Acceptance criteria
- Admin creates a user → connected admins and managers receive user.created within 2 seconds
- A connected member receives no directory events
- A connection without a valid token is refused

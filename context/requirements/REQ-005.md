## Rule
WHEN an admin deactivates a user, THE SYSTEM SHALL refuse that user's sign-in and every token issued before.
WHEN an admin reactivates a user, THE SYSTEM SHALL allow that user to sign in again.
IF an admin tries to deactivate their own account, THEN THE SYSTEM SHALL refuse it with 409.

## Acceptance criteria
- Admin deactivates a user → 200, status inactive
- Deactivated user signs in → 403, and their old token → 401
- Admin deactivates their own account → 409
- Reactivated user signs in → 200

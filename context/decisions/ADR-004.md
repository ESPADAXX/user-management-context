## Context
REQ-007 pushes directory changes to admins and managers within 2 seconds, never to members.

## Decision
Socket.IO on the API server. The client sends its JWT in the handshake (`auth.token`); invalid tokens are refused.
Admins and managers join the `directory` room; members join no room. Events: `user.created`, `user.updated`, `user.deactivated`, `user.reactivated`, `invitation.created`.

## Alternatives rejected
- Server-Sent Events: one-way is enough, but reconnection with auth and rooms is more code.
- Polling: cannot meet 2 seconds without heavy load.

## Consequences
Running several API instances requires the Socket.IO Redis adapter (see ADR-005).

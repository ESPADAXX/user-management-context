## Context
One instance serves the first release; the team wants zero setup for local work and CI.

## Decision
SQLite through Node's built-in `node:sqlite` module, one file set by `DATABASE_PATH` (`:memory:` in tests).
Emails are stored lowercase with a unique index, so duplicates are refused in any letter case (REQ-001).

## Alternatives rejected
- PostgreSQL from day one: more setup for no current need.

## Consequences
Moving to PostgreSQL (and the Socket.IO Redis adapter) becomes a new ADR that supersedes this one when the app needs more than one instance.

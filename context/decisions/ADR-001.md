## Context
A team of seven builds a user-management app. Requirements change often, so code, tests, the API contract and the context must move together in one pull request.

## Decision
One Git monorepo with npm workspaces:
- `apps/api`: Node.js 22, Express 4, Socket.IO 4
- `apps/web`: React 18 built with Vite
- `tools/context-server`: the MCP context server
- `context/`: the single source of truth

In production the API also serves the built web app, so one container is one deploy.

## Alternatives rejected
- Separate repositories per app: a requirement change would need several coordinated pull requests.
- Laravel API: the team's context tooling and the MCP SDK are JavaScript; one language keeps scripts shared.

## Consequences
- One CI pipeline runs every gate on every pull request.
- CODEOWNERS can give each folder its own approver.

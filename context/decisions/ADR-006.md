## Context
Several developers, and later their AI agents, must build from the same, current version of every client need.

## Decision
- Every need is a versioned file in `context/requirements/`, written in EARS.
- `context/manifest.json` is generated by `npm run context:manifest` and verified by CI.
- Pull requests declare `Implements: REQ-xxx@vN`; CI refuses outdated versions, missing traces and failing acceptance tests.
- The MCP context server is the only door agents use to read the context.

## Alternatives rejected
- Requirements in a wiki or in tickets only: no versions that CI can check.

## Consequences
Branch protection must require the `context-gates` checks (see `scripts/github/protect-main.sh`).
